# EstagioFinder
Trabalho individual da disciplina Webservices do 4º período de Tecnologia em Sistemas para Internet

Plataforma inteligente de oportunidades profissionais com o objetivo de encontrar e analisar oportunidades de estágio, jovem aprendiz e vagas para recém-formados próximas à cidade informada pelo usuário, considerando sua formação e características acadêmicas.
